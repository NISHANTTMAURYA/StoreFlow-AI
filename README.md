# StoreFlow AI

> **Dwell-Time & Bottleneck Mapping Engine for Physical Retail**  
> *A Privacy-Preserving, Ultra-Low-Cost, Edge-Native Computer Vision System*  
> Target Submission: IIT Bombay Technical Hackathon

---

## 📌 Overview
StoreFlow AI turns existing standard retail CCTV/RTSP security camera feeds into actionable operational intelligence:
- **Real-Time Foot-Traffic Heatmaps:** 2D metric planar density representations via homography projection.
- **Section Dwell-Time Calculation:** Sub-second accuracy distinguishing transit from browsing engagement.
- **Automated Bottleneck & Dead-Zone Detection:** Real-time divergence metrics alerting store managers of congestion or under-utilized aisles.
- **Zero-PII & GDPR/DPDP Compliant:** Ephemeral feature embeddings, zero facial recognition, no biometric storage.
